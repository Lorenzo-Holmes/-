# 冰箱清空计划 — 初版试玩

## 稳定入口

`play.html`

`play.html` 会加载 `index.html`，并处理少数浏览器全局 ID 兼容问题。

## 本地运行

从仓库根目录启动任意静态 HTTP server，例如：

```bash
python3 -m http.server 8080
```

然后打开：

```text
http://localhost:8080/game/play.html
```

## 当前初版内容

- 8 个关卡全部可玩；
- 25 种食材、20 道菜；
- 即期食材 / 时间 / 份数 / 热量四类约束；
- 四格料理区和配方匹配；
- 菜谱状态实时变化；
- 三星结算和下一关解锁；
- localStorage 保存最好星级和已解锁关卡。

## 视觉说明

仓库试玩版采用 Emoji / CSS 作为零依赖视觉，因此任何设备下载后都能直接运行。

开发阶段已经制作 DAY 1 正式冰箱、食材与菜品美术。后续接入正式美术时，不应修改已经验证的玩法与关卡核心结构。
