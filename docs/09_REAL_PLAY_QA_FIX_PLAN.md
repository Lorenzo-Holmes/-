## Batch A — 可发布基础

### QA-001 DOM 全局变量冲突

已完成：

- `game/index.html` 不再依赖 `finish.onclick`、`close.onclick`、`confirm.onclick` 等 DOM ID 自动暴露到 `window` 的行为。

- DAY 1 错误路线的目标反馈为：`鸡蛋用完了` / `1 道菜暂时做不了了`。

### QA-006 非满分结算闭环
