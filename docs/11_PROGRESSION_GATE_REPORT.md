日期：2026-09-05

## 规则

RISK-001 已按推荐方案落地：

- 新玩家首次推进时，至少成功完成 1 道菜才解锁下一关。
- 不要求 100% 清空率。
- 不要求三星。
- 已经解锁的下一关不会因为回头重玩 0 道菜而重新锁住。
- DAY 8 至少完成 1 道菜后才写入 `P.completed=true` 并进入 8 / 8 完成态。
