# 00 — 项目总纲 / Project Charter

## 项目名称

《冰箱清空计划》

## 一句话定义

在食材过期前，用有限食材组合出尽可能合理的菜，最大化待处理食材利用率并减少浪费。

## 项目定位

- 类型：轻策略 / 资源分配 / 休闲益智。
- 平台：小红书小工具，手机竖屏优先。
- 单局：自然游玩约 60–120 秒。
- 核心不是“找菜谱”，而是“有限资源如何分配”。

## 核心玩家问题

玩家在每一次制作前都应该自然产生：

> “用了这个以后，我还能做什么？”

若玩家只是在识别“番茄+鸡蛋=番茄炒蛋”，则项目退化为菜谱匹配器，核心玩法不成立。

## 核心循环

冰箱出现食材
→ 查看数量与保质状态
→ 选择/拖入料理区
→ 检查可能组合
→ 决定是否开火
→ 生成菜品并正式消耗食材
→ 剩余可制作方案变化
→ 继续规划
→ 主动结束今晚
→ 结算清空率、浪费、菜品、营养
→ 生成冰箱人格/结果卡
→ 重玩或下一关

## 四个比赛版主要指标

1. 冰箱清空率：以本关“今天必须处理”的食材为计算对象。
2. 浪费金额：未处理即期食材对应的游戏化价值。
3. 菜品数量：本局成功完成的菜数。
4. 营养评价：完成菜品的游戏化营养评分，不作为现实饮食建议。

## 四类关卡约束

1. 保质期：指定食材必须优先处理。
2. 人数：要求达到一定人份。
3. 热量：总热量不超过目标。
4. 烹饪时间：菜品累计游戏内烹饪时间不超过目标。

注意：“单局 60–120 秒”是自然游玩时长，不是现实倒计时。比赛版不使用真实倒计时。

## 核心游戏性来源

万能食材会被多道菜争抢。例如鸡蛋既能做番茄炒蛋，也能做蛋炒饭、牛奶蒸蛋、洋葱煎蛋。玩家必须决定有限鸡蛋应分配给哪一道菜。

设计应优先制造“合理但非最优”的选择，而不是明显的错误答案。

## 首发范围锁定

- 8 个关卡。
- 约 25 种食材。
- 约 20 道菜。
- 4 类规则。
- 1 个完整冰箱主场景。
- 1 套结算分享卡。

## 游戏调性

生活化、轻松、有一点“收拾残局”的爽感。

美术关键词：

- 冰箱内部冷白光。
- 有真实生活痕迹。
- 半透明保鲜盒、塑料袋、切开的剩余食材、日期贴纸。
- 轻写实 2.5D + 柔和卡通化。
- 食材辨识度高。

不要做成：

- 菜谱 App。
- 健康 App。
- 记账 App。
- 外卖 App。
- 复杂经营游戏。

## 传播机制

结算应生成具有截图价值的“冰箱人格”结果卡，例如：

- 极限清库存型
- 精算规划型
- 豪华料理型
- 鸡蛋依赖型
- 营养管理型
- 明天再说型

传播文案基准：

> 你的冰箱里没有剩菜，只有还没被想出来的晚饭。

## 当前阶段 Gate

只先验证 DAY 1 Vertical Slice。

通过条件不是“功能完整”，而是首次未达到 100% 的玩家能够理解自己为什么做错，并愿意马上重开优化。

在这一 Gate 通过前，不应优先扩内容。
