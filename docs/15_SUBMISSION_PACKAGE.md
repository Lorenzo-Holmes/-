## 产品介绍

### 标题

冰箱清空计划：三个鸡蛋，怎么安排四道菜？

### 一句话

在食材过期前，用有限食材规划今晚的菜单；真正要想的不是“能做什么”，而是“做完这一道，还能做什么”。

### 投稿简介草稿

《冰箱清空计划》是一款手机竖屏轻策略游戏。冰箱里的食材数量有限，今天必须处理的东西却不能一直等。玩家通过点击或拖动食材组合菜品，在开火前决定如何分配资源。

DAY 1 只有三个鸡蛋，却有四道菜都需要它。每次选择都会改变后面的可做方案。结束今晚后，游戏展示清空率、剩余即期食材和浪费金额；不满意时，可以直接重新规划。

比赛版内容为八个关卡、二十五种食材、二十道菜，逐步叠加保质期、人数、热量和累计烹饪时间约束。不设置现实倒计时，也不要求三星才能继续，让玩家把注意力放在自己的决策上。

### 展示重点

主卖点是有限资源引起的选择取舍，不是菜谱数量、烹饪动画或 AI 功能。营养、热量与浪费金额属于游戏化设定，不作为现实饮食或市场价格依据。

### 封面文案

主标题：三个鸡蛋，四道菜。

副标题：先做哪一道，真的有区别。

封面使用真实运行画面，保留能辨认的冰箱和食材；不把“今天”、库存等 UI 烘焙进素材，不捏造玩法截图。

## 采集路线（录制人员使用，不写入新手教程）

失败路线：番茄炒蛋 → 蛋炒饭 → 洋葱煎蛋，留下牛奶，期望 75%、¥4.80。

重玩路线：番茄炒蛋 → 蛋炒饭 → 牛奶蒸蛋，期望 100%、¥0、精算规划型。
