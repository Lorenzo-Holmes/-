# 08 — 初版游戏实现状态 v0.1

## 当前状态

**初版游戏已完成，可试玩。**

稳定入口：[`../game/play.html`](../game/play.html)

核心实现文件：[`../game/index.html`](../game/index.html)

## 已完成范围

- 8 个首发关卡全部可玩。
- 25 种食材数据池已接入。
- 20 道首发菜品已接入。
- 四类规则已实现：即期食材、累计烹饪时间、总份数、总热量。
- 四格料理区与配方精确匹配已实现。
- 点击食材、撤回、清空、开火、库存扣除已实现。
- “今晚还能做”菜谱抽屉已实现，并区分：可以做 / 会超目标 / 做不了 / 已完成。
- 时间、份数、热量的 READY 预览已实现。
- 菜品完成后会反馈被关闭的后续选择。
- 玩家可在仍有即期食材时提前结束，并收到浪费确认。
- 三星结算、清空率、营养等级、冰箱人格已实现。
- 完成结算即可解锁下一关，不强制三星。
- 关卡进度与最好星级通过 localStorage 持久化。
- 手机竖屏布局优先，并兼容较矮屏幕。

## 关卡验证

开发期间对 8 个关卡的三星核心路线进行了程序化库存模拟。

验证结果：8 / 8 路线可达三星。

最终关三星路线验证结果：

- 即期食材：6 / 6；
- 时间：38 / 40 分钟；
- 份数：7 / 7；
- 热量：1180 / 1250 kcal。

与 `06_LEVEL_PROGRESSION.md` 的正式设计一致。

### 本地美术增强交付包

## 下一阶段建议

初版之后优先级建议：

1. 将 DAY 1 正式视觉资产接入仓库运行版；
2. 做首次真实用户试玩并记录第一道菜、首次成绩、是否重开、第二次成绩；
3. 根据试玩结果只调整机会成本反馈和关卡数值；
4. 再补 DAY 2–8 正式食材 / 菜品美术；
5. 最后做小红书比赛投稿包装与演示录屏。

不要在试玩前新增商城、养成、AI 菜谱、联机、排行榜等非核心系统。
