## 真实试玩后已修复

### 稳定性与结算

- 不再依赖 DOM ID 自动暴露到 `window` 绑定关键事件。
- `play.html` 不再用 iframe 点击拦截修补 `close/confirm`。
- `cook()` / 增强烹饪提交保持先验证、后一次性扣库存。
- 机会成本反馈会指出真正耗尽并关闭方案的资源。
- DAY 1 恢复浪费金额；留牛奶路线为 ¥4.80。
- 非 100% 结算优先“重新规划”。
- DAY 1 100% 恢复“精算规划型 / 三个鸡蛋，一个都没白用 / 今晚 MVP：鸡蛋”。

### 核心交互

- 点击菜谱只高亮对应食材，不自动替玩家选择。
- 食材支持 Pointer Events 拖拽，同时保留点击快速加入。
- 首次 DAY 1 恢复两步强制教学，成功第一次开火后不再重复。
- 主要触控区提高到约 44×44px。
- 短屏 / 窄屏使用 `100svh` 弹性布局和可换行即期目标。

### 奖励与完整性

- READY 后开火增加约 800ms 的轻量烹饪反馈，并在期间锁定关键操作。
- 完成菜品出现短奖励卡。
- “今晚菜单”显示缩略条，点击完成菜可看人份、时间、kcal。
- DAY 8 结算后进入 `8 / 8` 完成首页，并显示最好总星数。
